# Inter Tight

`inter-tight-latin.woff2` is the variable-weight Latin subset of the existing Inter Tight typeface, preserved from this project's Next.js development font cache. The cached CSS identifies it as Inter Tight, normal style, weights 100–900.

Self-hosting removes the build-time dependency on Google Fonts. Non-Latin characters use the configured system fallback.
